# plainbalance icon provenance

The founder-preferred original white corner on the black rounded square is original MPL-2.0 product artwork, independent of the corporate logo. Its existing geometry and all PNG/ICNS bytes are retained. The internal `placeholder/` path is historical; final publication review remains pending. `icon.png` is copied unchanged from `brand/plainbalance/placeholder/icon-128.png`. `plainbalance.icns` contains the 16,32,64,128,256,512,1024px PNG family generated by `brand/plainbalance/render.swift` from `placeholder/app-icon.svg`, as PNG-backed ICNS chunks. The same source is used by the Swift desktop builder. `release/source-files.json` records exact binary SHA-256 values. Corporate SVGs remain byte-for-byte unchanged. Windows/Linux packaging remains unverified.
